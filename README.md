# Akandwanaho Simon Katozi — Portfolio

Responsive portfolio built with HTML5, CSS3, Bootstrap 5, and local photo assets.
The Bootstrap grid adapts the gallery, skills, and contact cards to smaller screens.

## Run locally

Open `index.html` in a browser. Bootstrap is loaded from jsDelivr, so its styling needs an internet connection.

## Git and GitHub Pages

Track changes with Git and push this project to a GitHub repository. In the repository,
open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`,
then save. GitHub Pages uses the root `index.html` as the site entry point.
